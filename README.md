# elementarmagnete

Interaktive Lehranimation für Physik Klasse 7 (Magnetismus): Magnetisieren und
Entmagnetisieren eines Eisennagels im Modell der Elementarmagnete.

## Start

`nagel_magnetisierung.html` per Doppelklick öffnen (Chrome, Edge oder Firefox).
Die Datei läuft komplett offline, ohne Internet und ohne weitere Dateien.
Mit **F** in den Vollbildmodus wechseln.

## Ablauf

1. Wie wird ein Nagel zum Magneten? (Außenansicht, Büroklammern bleiben liegen)
2. Blick ins Innere (ungeordnete Elementarmagnete)
3. Magnetisieren durch Streichen (3 Striche, Rückweg durch die Luft)
4. Der Nagel ist magnetisiert (Pole, Büroklammern, optional Kompassprobe)
5. Entmagnetisieren durch Klopfen
6. Entmagnetisieren durch Erhitzen (Curie-Temperatur 770 °C)
7. Zusammenfassung

Bonus (über die Schaltflächen auf der Zusammenfassung, das Menü oder die Tasten):
Magnet teilen (**T**) und Umpolen (**U**).

Vor den Etappen 3, 5, 6 und Bonus „Magnet teilen“ erscheint eine Vorhersage-Karte.

## Tasten

| Taste | Funktion |
|---|---|
| Leertaste / → | weiter (bzw. Vorhersage auflösen, nächster Strich) |
| ← | zurück |
| R / N | Etappe neu starten / alles auf Anfang |
| F / Z / I | Vollbild / Zeitlupe (40 %) / Außen- oder Innenansicht |
| V | Vorhersage-Pausen an/aus |
| K / L / C | Kompassprobe / Feldlinien / Klammern im Inneren |
| T / U | Bonus: Magnet teilen / Bonus: Umpolen |
| B / H | Bedienfeld aus/ein / Bedienhilfe |

Präsentations-Fernbedienungen (Bild auf/ab) funktionieren wie ← und →.
